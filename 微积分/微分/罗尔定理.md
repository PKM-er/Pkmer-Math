设函数 $f(x)$ 满足: 
1. 在闭区间 $[a,b]$ 上[[连续性|连续]]
2. 在开区间 $(a,b)$ 可导
3. $f(a)=f(b)$
则 $(a,b)$ 至少存在一个点 $c$, 使得：
$$f ^ { \prime } ( c ) = 0$$
证明：由[[最值定理]]，$f$ 在 $[a,b]$ 上取得最大值和最小值。若二者相等，则 $f$ 为常数，结论成立；否则，因 $f(a)=f(b)$，至少有一个极值在内部点 $c$ 取得。内部极大值处，右侧差商非正、左侧差商非负；导数存在时两者极限相同，只能为 $0$。极小值同理。这就是本证明使用的费马引理。
罗尔定理可以推广为[[拉格朗日中值定理]]
