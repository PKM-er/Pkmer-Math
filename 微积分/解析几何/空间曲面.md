# 背景
在空间解析几何中, 关于曲面的研究有两个基本问题:
1. 已知曲面作为点的几何轨迹时, 建立这个曲面方程
2. 已知坐标间的方程, 研究方程表示的曲面形状

[[空间平面]]属于第一类, 空间曲面就是此类问题的推广. 


# 常见曲面
## 球面
$$(x-x_0)^2+(y-y_0)^2+(z-z_0)^2=R^2$$
或
$$Ax^2+Ay^2+Az^2+Dx+Ey+Fz+G=0$$
要求 $A\ne0$，配方后半径平方 $R^2=(D^2+E^2+F^2)/(4A^2)-G/A$ 必须为正；等于零是点，小于零为空集。

## 旋转曲面
### 圆锥面
$$z^2 = x^2 + y^2$$

### 旋转单叶双曲面
下面方程须 $a=b>0,c>0$ 才是绕 $z$ 轴的旋转曲面；$a\ne b$ 是一般椭圆截面双曲面。
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$$

### 旋转双叶双曲面
同样取 $a=b>0,c>0$。
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = -1$$

## 柱面

### 准线
准线是生成柱面的固定曲线，例如直线、圆、抛物线等。

### 母线
母线彼此平行于一个固定非零方向，且通过准线上的各点；母线并不是“与准线平行”。

### 圆柱面
$$(x - x_0)^2 + (y - y_0)^2 = R^2$$

### 抛物柱面
$$z = Ax^2 + By + C$$

## 二次曲面
以下参数 $a,b,c$ 取正值；抛物柱面式中取 $A\ne0$，母线方向为 $(0,1,B)$。

### 椭圆柱面
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$

### 椭球面
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1$$

### 单叶双曲面
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$$

### 双叶双曲面
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = -1$$

### 椭圆抛物面
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 2z$$

### 双曲抛物面(马鞍面)
$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 2z$$
