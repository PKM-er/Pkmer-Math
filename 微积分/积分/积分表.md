常用基本积分公式表，用于求[[不定积分]]，按被积函数类型分类。

## 幂指函数

$$\int k dx = kx + C$$
$$\int x^n dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)$$
$$\int \frac{1}{x} dx = \ln|x| + C$$
$$\int e^x dx = e^x + C$$
$$\int a^x dx = \frac{a^x}{\ln a} + C \quad (a > 0, a \neq 1)$$
## 三角函数
$$\int \sin x dx = -\cos x + C$$
$$\int \cos x dx = \sin x + C$$
$$\int \tan x dx = -\ln|\cos x| + C$$
$$\int \cot x dx = \ln|\sin x| + C$$
$$\int \sec x dx = \ln|\sec x + \tan x| + C$$
$$\int \csc x dx = \ln|\csc x - \cot x| + C$$
$$\int \sec^2 x dx = \tan x + C$$
$$\int \csc^2 x dx = -\cot x + C$$
$$\int \frac{1}{\sin^2 x} dx = -\cot x + C$$
$$\int \frac{1}{1 - \sin x} dx = \tan x + \sec x + C$$
## 反三角函数
$$\int \frac{1}{\sqrt{1-x^2}} dx = \arcsin x + C$$
$$\int \frac{1}{\sqrt{a^2 - x^2}} dx = \arcsin \frac{x}{a} + C \quad (a > 0)$$
$$\int -\frac{1}{\sqrt{1-x^2}} dx = \arccos x + C$$
$$\int \frac{1}{1+x^2} dx = \arctan x + C$$
$$\int -\frac{1}{x^2+1} dx = \text{arccot} \, x + C$$
$$\int \frac{1}{|x|\sqrt{x^2-1}} dx = \text{arcsec} \, x + C$$
$$\int -\frac{1}{|x|\sqrt{x^2-1}} dx = \text{arccsc} \, x + C$$
## 反双曲函数

$$
\int \frac{1}{\sqrt{x^2 + a^2}} \, dx = \ln|x + \sqrt{x^2 + a^2}| + C = \text{arcsinh}\left(\frac{x}{a}\right) + C
$$

$$
\int \frac{1}{\sqrt{x^2 - a^2}} \, dx = \ln|x + \sqrt{x^2 - a^2}| + C = \text{arccosh}\left(\frac{x}{a}\right) + C
$$

$$
\int \frac{1}{1 - x^2} \, dx = \frac{1}{2} \ln\left|\frac{1 + x}{1 - x}\right| + C = \text{arctanh}(x) + C \quad (|x| < 1)
$$

$$
\int \frac{1}{x^2 - 1} \, dx = \frac{1}{2} \ln\left|\frac{x - 1}{x + 1}\right| + C = -\text{arccoth}(x) + C \quad (|x| > 1)
$$

$$
\int \frac{1}{x \sqrt{1 - x^2}} \, dx = -\ln\frac{1 + \sqrt{1 - x^2}}{x} + C = -\text{arcsech}(x) + C \quad (0 < x < 1)
$$

$$
\int \frac{1}{|x| \sqrt{1 + x^2}} \, dx = -\text{arccsch}(x) + C \quad (x \neq 0)
$$

## 分支与常数

实幂公式一般在 $x>0$ 使用；整数幂等可在其余定义区间延伸。所有原函数等式都在被积函数连续的区间上理解。反正割、反余割采用[[常用求导公式]]的常用主值分支，要求 $|x|>1$，因此分母必须有 $|x|$。

含 $x^2\pm a^2$ 的两条反双曲公式设 $a>0$。其中 $\operatorname{arcosh}(x/a)$ 只适用于 $x>a$；在 $x<-a$ 应写成 $-\operatorname{arcosh}(-x/a)+C$。带绝对值的对数式适用于这两个区间，积分常数分别独立。对数式与反双曲式之间的固定常数已吸收到各自的 $C$ 中。

$\tan x+\sec x$ 在 $\cos x=0,\sin x=-1$ 处产生额外的可去间断点；原被积函数 $1/(1-\sin x)$ 在这些点有定义。需要覆盖这样的区间时，原函数可统一写作 $\tan(\pi/4+x/2)+C$。
