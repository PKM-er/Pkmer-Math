## 幂指函数

其中 $a$, $c$, $n$ 都是常数：
$$\frac{d}{dx} (c) = 0$$
$$\frac{d}{dx} (x^n) = nx^{n-1}$$
$$\frac{d}{dx} (a^x) = a^x \ln(a),(a > 0)$$
$$\frac{d}{dx} (\log_a x) = \frac{1}{x \ln(a)},(a > 0, a \neq 1)$$
## 三角函数

$$\frac{d}{dx}(\sin(x)) = \cos(x)$$
$$\frac{d}{dx}(\cos(x)) = -\sin(x)$$
$$\frac{d}{dx}(\tan(x)) = \sec^2(x)$$
$$\frac{d}{dx}(\cot(x)) = -\csc^2(x)$$
$$\frac{d}{dx}(\sec(x)) = \sec(x) \tan(x)$$
$$\frac{d}{dx}(\csc(x)) = -\csc(x) \cot(x)$$

## 反双曲函数

| 函数 | 定义域 | 导数 |
| :--- | :--- | :--- |
| $\operatorname{arsh}x$ 或 $\operatorname{arsinh}x$ | $x\in\mathbb R$ | $\displaystyle \frac{d}{dx}\operatorname{arsh}x=\frac{1}{\sqrt{1+x^2}}$ |
| $\operatorname{arch}x$ 或 $\operatorname{arcosh}x$ | $x>1$ | $\displaystyle \frac{d}{dx}\operatorname{arch}x=\frac{1}{\sqrt{x^2-1}}$ |
| $\operatorname{arth}x$ 或 $\operatorname{artanh}x$ | $|x|<1$ | $\displaystyle \frac{d}{dx}\operatorname{arth}x=\frac{1}{1-x^2}$ |
| $\operatorname{arsech}x$ | $0<x<1$ | $\displaystyle \frac{d}{dx}\operatorname{arsech}x=-\frac{1}{x\sqrt{1-x^2}}$ |
| $\operatorname{arcsch}x$ | $x\ne0$ | $\displaystyle \frac{d}{dx}\operatorname{arcsch}x=-\frac{1}{|x|\sqrt{1+x^2}}$ |

## 导数与积分的配套验证

反三角与反双曲函数的导数与常见积分表相互一致。在同一主值分支下有

$$\frac{d}{dx}\arcsin x=\frac{1}{\sqrt{1-x^2}}\iff \int \frac{1}{\sqrt{1-x^2}}dx=\arcsin x+C,$$

$$\frac{d}{dx}\arctan x=\frac{1}{1+x^2}\iff \int \frac{1}{1+x^2}dx=\arctan x+C,$$

$$\frac{d}{dx}\operatorname{arsh}x=\frac{1}{\sqrt{1+x^2}}\iff \int \frac{1}{\sqrt{1+x^2}}dx=\operatorname{arsh}x+C,$$

$$\frac{d}{dx}\operatorname{arch}x=\frac{1}{\sqrt{x^2-1}}\iff \int \frac{1}{\sqrt{x^2-a^2}}dx=\operatorname{arcosh}(x/a)+C,\ (a>0),$$

$$\frac{d}{dx}\operatorname{arth}x=\frac{1}{1-x^2}\iff \int \frac{1}{1-x^2}dx=\operatorname{arth}x+C,\ (|x|<1).$$

端点与主值分支必须一致使用：$\arcsin,\arccos$ 在端点 $\pm1$ 两侧极限可存在，但通常不再有有限导数；$\operatorname{arcsec},\operatorname{arccsc},\operatorname{arch}$ 等在定义域边界或分段区间交界处也按对应侧导数处理。

## 定义域约定

实幂 $x^n$ 在一般实指数下取 $x>0$；非负整数指数按多项式可扩展到全实轴。对数公式要求 $x>0$。三角函数公式使用弧度制，且应排除分母为零之处。

反三角函数采用常见主值区间：$\arcsin,\arccos$ 取 $x\in(-1,1)$ 时的导数公式；$\arctan,\operatorname{arccot}$ 在 $\mathbb R$；$\operatorname{arcsec},\operatorname{arccsc}$ 要求 $|x|>1$ 且按上表主值。反双曲函数按定义域：$\operatorname{arsh}\in\mathbb R,\operatorname{arch}\in(1,\infty),\operatorname{arth}\in(-1,1)$。不同主值分支不可混用同一符号公式。导数公式在对应区间端点往往退化为一侧导数或不存在。

对应积分统一式见[[积分表]] 与[[反双曲余弦]]、[[反双曲正弦]]、[[反双曲正切]]。
