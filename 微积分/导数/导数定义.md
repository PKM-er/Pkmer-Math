## 函数在某一点的导数

设 $f$ 在 $x_0$ 的邻域有定义。若下列差商极限存在且有限，称其为 $f'(x_0)$，几何上是图像在该点的切线斜率：
$$\lim_{ x \to x_{0} } \dfrac{f(x)-f(x_{0})}{x-x_{0}} $$

## 函数的导函数

在各可导点处 $y$ 的变化率关于$x$的函数$y'$称为函数$y=f(x)$的导函数, 写作$y'=f'(x)$. 由此可见导数$y'$的定义依赖于原函数$y$

“导数”既可指某点的数值，也可指导函数；可用 $f'(x_0)$ 与 $f'$ 明确区分。二者是同一概念的逐点值与函数形式，关系如下：

| 小结   | $\lim_{ x \to x_{0} } \dfrac{f(x)-f(x_{0})}{x-x_{0}}$ | $f'(x)$ |
| :--- | :---------------------------------------------------- | :------ |
| 准确描述 | 函数在某一点的导数                                             | 导函数     |
| 通俗说法 | 导数                                                    | 导数      |

## 单侧导数

如果使用极限来定义函数的导数, 那么根据极限的定义, 导数也能分为左导数$f'(x^-)$和右导数$f'(x^+)$.
连续函数的左右导数不一定存在，也不一定相等（如 $f(x)=|x|$ 在 $x=0$ 处连续，但左、右导数分别为 $-1$ 与 $1$）。左右导数与可导性的讨论见[[单侧导数]]，可导与连续的关系见[[可导与连续的关系]]

## 导数的几何意义
