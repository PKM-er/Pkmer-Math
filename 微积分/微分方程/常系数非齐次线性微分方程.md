二阶常系数非齐次线性微分方程的一般形式
$$y''+py'+qy=f(x)$$
由[[二阶线性微分方程解的结构#定理3]]可知, 求解二阶常系数非齐次线性微分方程的通解, 归结为求对应齐次方程的通解和非齐次方程本身的一个特解

对应齐次方程的通解在[[常系数齐次线性微分方程]]得到解决, 所以这里只讨论求特解的方法. 

# 待定系数法
这里讨论$f(x)$的两种形式
## 指数解
$$f(x)=e^{ \lambda x }P_{m}(x)$$
由于多项式与指数函数乘积的导数仍是同一指数乘以多项式, 可以推测$y^*=R(x)e^{ \lambda x }$为一个特解,

(推导略)

特解形式为:
$$y^*=x^kR_{m}(x)e^{ \lambda x }$$
其中$R_{m}(x)$是与$P_{m}(x)$同次的多项式, 
$$R_m(x)=b_0x^m+b_1x^{m-1}+\cdots+b_mx^{0}$$
$k\in\{0,1,2\}$由 $\lambda$ 作为特征根的重数决定,
- 若$\lambda$不是特征方程的根, $k=0$
- 若$\lambda$是特征方程的单根, $k=1$
- 若$\lambda$是特征方程的重根, $k=2$

将特解带回方程, 解得系数 $b_0$, $b_1$, ... $b_m$


>[!example]+
>
$$y'' - 3y' + 2y = e^{2x}$$
> 1. 对应的齐次方程：$y'' - 3y' + 2y = 0$
> 求解特征方程：$r^2 - 3r + 2 = 0$, 得$r = 1, 2$
> 齐次方程的通解：$y_h = C_1 e^x + C_2 e^{2x}$
> 2. 由于非齐次项$f(x) = e^{2x}$，且$\lambda = 2$是特征方程的单根，所以设$k=1$。
>
$$y_p = x b_0 e^{2x}$$
> 3. 代入原方程：
>
$$(4b_0 e^{2x} + 4b_0x e^{2x}) - 3(b_0 e^{2x} + 2b_0x e^{2x}) + 2x b_0 e^{2x} = e^{2x}$$
> 整理并合并同类项：$b_0 e^{2x} = e^{2x}$ , 解得$b_0 = 1$。
> 4. 构造非齐次的通解：
>
$$y = C_1 e^x + C_2 e^{2x} + x e^{2x}$$

## 圆函数解
以下设方程系数、$\lambda,\omega$ 为实数，且 $\omega\ne0$；$\omega=0$ 回到上一节。
$$f(x)=e^{ \lambda x }[P_{l}(x)\cos(\omega x)+Q_{n}(x)\sin(\omega x)]$$

应用欧拉公式变为复指数求解, 推导略

特解形式为:
$$y^*=x^{k}e^{ \lambda x }[R_{m}^{(1)}(x)\cos(\omega x)+R_{m}^{(2)}(x)\sin(\omega x)]$$
$R_{m}^{(1)}(x)$、$R_{m}^{(2)}(x)$ 是次数不超过 $m$ 的待定多项式,

$m=max(l,n)$, 

$k$是特征方程中 $\lambda+\omega i$或$\lambda-\omega i$ 这两个根的重复次数(二阶只能取到$\{0,1\}$)


 >[!example]+
> 考虑方程：
>
$$y'' + py' + qy = \cos(\omega x)$$
> 这里余弦系数为常数 1，正弦系数为零多项式。
> 
> 1. **应用欧拉公式**：
>    使用欧拉公式将$\cos(\omega x)$表达为复指数的实部：
>
$$\cos(\omega x) = \frac{e^{i\omega x} + e^{-i\omega x}}{2}$$
> 
> 2. **假设特解形式**：
>    假设特解的形式为：
>
$$y^* = x^k [A \cos(\omega x) + B \sin(\omega x)]$$
>    其中，$k$是特征方程中$i\omega$或$-i\omega$这两个根的重复次数。
> 
> 3. **代入原方程求解**：
>    将假设的特解形式代入原方程，并求解未知系数$A$和$B$。

## 复系数非齐次线性微分方程

设 $L(D)$ 为常系数线性微分算子，最高阶系数非零。恒等式
$$L(D)[e^{\lambda x}v(x)]=e^{\lambda x}L(D+\lambda)v(x)$$
由乘积法则得到。若 $\lambda$ 是特征多项式的 $k$ 重根（非根时 $k=0$），对 $e^{\lambda x}P_m(x)$ 可设 $y_p=x^ke^{\lambda x}R_m(x)$，代入解多项式系数。系数、$\lambda$ 和解均可为复数。

若右端含 $e^{\lambda x}[P(x)\cos\omega x+Q(x)\sin\omega x]$，先按欧拉公式拆为两个指数频率 $\lambda+i\omega$、$\lambda-i\omega$，分别查看其重数 $k_+,k_-$，分别试解后相加。复系数方程的两根不一定共轭，故不能默认两个频率共用同一个 $x^k$。

例如 $y'-iy=\cos x$，拆成 $(e^{ix}+e^{-ix})/2$。第一项共振，第二项不共振，一个特解为
$$y_p=\frac{x}{2}e^{ix}+\frac{i}{4}e^{-ix}.$$
直接计算 $y_p'-iy_p=(e^{ix}+e^{-ix})/2$ 即验证。复系数算子通常不与“取实部”交换，不能把复解的实部自动当作原方程的实解。

## 非齐次线性偏微分方程

对常系数算子 $L(\partial_x,\partial_y)$，仍可利用
$$L(\partial_x,\partial_y)[e^{\lambda x+\mu y}v]
=e^{\lambda x+\mu y}L(\partial_x+\lambda,\partial_y+\mu)v.$$
指数乘多项式、或经欧拉公式拆开的三角项可用它构造试解，但多项式次数和形式由具体算子决定，不能统一规定为 $x^ky^lR_m$ 并保证成功。变系数算子更不能直接套用常系数的规则；求一个特解也没有解决边界条件或完整解空间。

例如
$$u_{xx}+u_{yy}=e^{\lambda x+\mu y}.$$
若 $\lambda^2+\mu^2\ne0$，设 $u_p=Ae^{\lambda x+\mu y}$，代入得
$$A(\lambda^2+\mu^2)=1,\qquad u_p=\frac{e^{\lambda x+\mu y}}{\lambda^2+\mu^2}.$$
这里应求系数 $A$，不能由试解失败反过来要求题目参数满足 $\lambda^2+\mu^2=1$。

当 $\lambda=\mu=0$，一个特解为 $u_p=x^2/2$。若参数为复数且 $\lambda^2+\mu^2=0$、$\lambda\ne0$，可取 $u_p=xe^{\lambda x+\mu y}/(2\lambda)$。直接求二阶偏导即可核验这些分支。完整解为 $u=u_p+h$，其中 $h$ 满足[[拉普拉斯方程]]，还须利用边界条件确定 $h$。

该圆函数例题可算到底：令 $d=q-\omega^2$。若 $d^2+p^2\omega^2\ne0$，有
$$A=\frac{d}{d^2+p^2\omega^2},\qquad B=\frac{p\omega}{d^2+p^2\omega^2}.$$
若分母为零（实系数且 $\omega\ne0$ 时即 $p=0,q=\omega^2$），取共振特解 $y_p=x\sin(\omega x)/(2\omega)$。以上均可求导代回核验。

待定系数法只覆盖适合的指数、多项式、三角及其有限组合；一般连续右端改用[[二阶线性微分方程解的结构#常数变易法]]。
