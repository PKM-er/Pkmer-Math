## 核心思想

线性代数的抽象概念——[[线性空间|向量空间]]、[[子空间]]、[[核]]、[[像空间|像]]、[[基]]、[[维数]]——本质上是把「解方程组」和「矩阵运算」抽象成**几何与代数结构**。看懂这一步，就能处理「矩阵对角化」之外的概念型考题：题目引入的新名词，大多只是这些结构在不同层面的叫法。

## 概念层级

- **[[线性空间]]**（向量空间）＝大宇宙：具备满足向量空间公理的加法与数乘的集合，最常见的是 $\mathbb{R}^n$。
- **[[子空间]]**＝宇宙中「过原点且平直」的区域：过原点的点、直线、平面。判定三条件：含零向量、加法封闭、数乘封闭。
- **[[仿射空间]]**＝子空间的平移，可能经过原点；相容非齐次方程组 $Ax=b$（$b\neq 0$）的解集就是仿射空间，即一个特解加[[零空间]]。
- **[[基]] 与 [[维数]]**＝描述空间所需「最精简的坐标轴」及其个数。

## 核心概念与矩阵语言的对应

| 抽象概念 | 直观含义 | 矩阵语言 |
| --- | --- | --- |
| [[线性空间]] | 对加法数乘封闭的集合 | $\mathbb{R}^n$ 全体列向量 |
| [[子空间]] | 过原点的点 / 线 / 面 | 过原点的平直区域 |
| [[核]]（[[零空间]]） | 被变换压成零的输入 | $Ax=0$ 的解集 |
| [[像空间]]（列空间） | 变换能到达的输出 | 列向量张成的空间 |
| [[基]] | 线性无关且能张成整个空间 | 基础解系 / 极大线性无关组 |
| [[维数]] | 基中向量的个数 | 自由变量数（核）/ 秩（像） |
| [[维数定理]] | 保留＋牺牲＝总维数 | 主元数＋自由变量数＝未知数个数 |

## 线性变换的核与像

[[线性变换]]在有限维空间选定基后可以用矩阵表示；核与像是它的两个核心结构：

- **[[核]]（零空间）**：被压成零向量的输入，即 $Ax=0$ 的全部解——变换「牺牲掉」的维度。
- **[[像空间]]（列空间）**：输出能达到的范围，即列向量的线性组合——变换「保留下」的维度。

两者由 **[[维数定理]]（秩-零化度定理）** 记账：

$$
\dim V = \dim(\mathrm{Ker}(f)) + \dim(\mathrm{Im}(f)),
\qquad
n = \mathrm{nullity}(A) + \mathrm{rank}(A).
$$

输入空间的维数，恰好拆成「被压成零的维数」与「保留下来的维数」两部分。

## 三层映射复习法

每个概念都可以在三个层面之间自由翻译：

1. **几何层**：它是线、面、投影还是压缩？
2. **算子层**：它是核、像还是基？
3. **矩阵层**：它对应 $Ax=0$、列向量组还是秩？

能在这三层之间自由翻译，概念型考题即可迎刃而解。
