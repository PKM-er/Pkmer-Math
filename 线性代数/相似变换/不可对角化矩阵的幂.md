[[对角化]]只能处理有 $n$ 个线性无关[[特征向量]]的矩阵。以下在特征多项式分裂的数域中讨论，幂指数 $n$ 为非负整数。当矩阵有重[[特征值]]且特征向量不足（[[几何重数]] $<$ [[代数重数]]）时矩阵**不可对角化**，此时算 $A^n$ 需改用 [[凯莱-哈密顿定理]] 的带余除法或 [[幂零矩阵]] 拆分。

> [!NOTE] 前置知识
> 建议按顺序掌握：[[特征值]]与[[特征多项式]]（求特征根）→ [[特征向量]]与[[几何重数]]、[[代数重数]]（判断能否[[对角化]]）→ [[凯莱-哈密顿定理]]与[[最小多项式]]（方法一的降次依据）→ [[幂零矩阵]]与[[二项式定理]]（方法二的截断依据）。全貌见[[相似变换概述]]。

以一个最经典的不可对角化矩阵为例，同时演示这两种解法：

$$A = \begin{pmatrix} 3 & -1 \\ 1 & 1 \end{pmatrix}$$

特征方程为 $\det(\lambda I - A) = (\lambda - 3)(\lambda - 1) + 1 = (\lambda - 2)^2 = 0$，重特征值 $\lambda = 2$。
求解 $(A - 2I)x = 0$ 仅有 1 个线性无关特征向量，因此 **$A$ 不可对角化**（见[[对角化#条件]]）。

---

## 方法一：Cayley-Hamilton 定理 + 多项式除法

**核心逻辑**
根据 [[凯莱-哈密顿定理]]，矩阵满足自身的特征方程，即 $(A - 2I)^2 = O$（零矩阵）。
将 $\lambda^n$ 除以特征多项式 $(\lambda - 2)^2$（即[[多项式除法|带余除法]]），得到商式 $Q(\lambda)$ 和一次余式 $R(\lambda) = c_1 \lambda + c_0$：

$$\lambda^n = Q(\lambda)(\lambda - 2)^2 + (c_1 \lambda + c_0)$$

将矩阵 $A$ 代入，由于 $(A - 2I)^2 = O$，前面一大串直接归零：

$$A^n = Q(A) \cdot O + (c_1 A + c_0 I) = c_1 A + c_0 I$$

算 $A^n$ 转化为**求标量系数 $c_1, c_0$**。

> [!NOTE] 重根处余式系数的求法
> 余式 $c_1\lambda+c_0$ 的次数低于除式 $(\lambda-2)^2$ 的次数。当 $\lambda=2$ 是重根时，只代入 $\lambda=2$ 只得一个方程，还须对等式两边求导后再代入 $\lambda=2$，才能解出两个系数。这是带余除法求余式系数的标准套路。

**计算步骤**

1. **代入特征根 $\lambda = 2$**：

$$2^n = 0 + (2c_1 + c_0) \implies 2c_1 + c_0 = 2^n \quad \text{--- (1)}$$

2. **两边对 $\lambda$ 求导后，再代入 $\lambda = 2$**：

$$n\lambda^{n-1} = Q'(\lambda)(\lambda - 2)^2 + Q(\lambda) \cdot 2(\lambda - 2) + c_1$$

代入 $\lambda = 2$：

$$n 2^{n-1} = c_1 \quad \text{--- (2)}$$

3. **联立解出系数**：

$$c_1 = n 2^{n-1}$$

$$c_0 = 2^n - 2c_1 = 2^n - 2(n 2^{n-1}) = (1 - n)2^n$$

4. **代回矩阵公式**：

$$A^n = n 2^{n-1} A + (1 - n)2^n I$$

> [!NOTE] 最小多项式视角
> 本例 $A-2I\neq O$ 而 $(A-2I)^2=O$，故 $A$ 的[[最小多项式]]恰为 $(\lambda-2)^2$，与特征多项式一致。若最小多项式次数更低，用最小多项式归零能把 $A^n$ 降到更少的项，计算更省。

## 方法二：幂零拆分 + 二项式定理

**展开之后做什么？**
拆分的核心目的就是**利用高次项直接归零（截断）**。
若 $m$ 阶矩阵只有单一特征值 $\lambda$，令 $N=A-\lambda I$，由特征多项式 $(t-\lambda)^m$ 和 Cayley–Hamilton 定理才可保证 $N^m=0$。有多个特征值时不能仅因阶数小就作这一判断。
本例的有限二项展开从第 3 项开始全部归零，剩下的就是两三个具体矩阵的简单加减法。

**计算步骤**

1. **拆成「数量矩阵 + [[幂零矩阵]]」**：
取唯一特征值 $\lambda=2$（不要求它已在原矩阵的对角线上）：

$$A = 2I + N \quad \text{其中 } N = A - 2I = \begin{pmatrix} 1 & -1 \\ 1 & -1 \end{pmatrix}$$

2. **验证幂零性（算 $N^2$）**：

$$N^2 = \begin{pmatrix} 1 & -1 \\ 1 & -1 \end{pmatrix}\begin{pmatrix} 1 & -1 \\ 1 & -1 \end{pmatrix} = \begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix} = O$$

因为 $N^2 = O$，所以所有 $k \ge 2$ 的项 $N^k = O$。

3. **二项式定理展开并截断**（$2I$ 与 $N$ 显然可交换——$2I$ 是数量矩阵，与任何矩阵交换）：

$$A^n = (2I + N)^n = \binom{n}{0}(2I)^n + \binom{n}{1}(2I)^{n-1} N^1 + \underbrace{\binom{n}{2}(2I)^{n-2} N^2 + \dots + N^n}_{\text{全部是 } O}$$

整个展开式只剩前两项（见[[二项式定理]]）：

$$A^n = 2^n I + n 2^{n-1} N$$

4. **把具体的矩阵代入相加（最终结果）**：

$$A^n = 2^n \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix} + n 2^{n-1} \begin{pmatrix} 1 & -1 \\ 1 & -1 \end{pmatrix} = \begin{pmatrix} 2^n + n 2^{n-1} & -n 2^{n-1} \\ n 2^{n-1} & 2^n - n 2^{n-1} \end{pmatrix}$$

---

## 两法比较

两个方法本质完全相通：方法一靠特征多项式（或[[最小多项式]]）把 $A^n$ 降次，方法二靠[[幂零矩阵]]的高次幂归零把二项式截断。若只有单一特征值，方法二可直接截断；若有多个特征值，可逐 Jordan 块处理或改用方法一。仅有重根和不可对角化不足以保证全矩阵能写成一个数量矩阵加幂零矩阵；需要统一公式或 $n$ 很大时，方法一直接给出 $A^n = c_1 A + c_0 I$ 的闭式。

## 后续

- [[Jordan标准型]]：不可对角化矩阵的一般标准形，方法二的幂零拆分正是 Jordan 块 $J=\lambda I+N$ 的高次幂公式。
- [[广义二项式定理]]：把二项式展开推广到实数幂 $\alpha$，可求 $(I+N)^{\alpha}$（如矩阵的平方根、逆矩阵）。
- [[矩阵指数]]：$e^{At}$ 在不可对角化时同样用 Jordan 块 + 幂零拆分计算。
