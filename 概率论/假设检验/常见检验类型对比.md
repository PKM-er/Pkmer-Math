常用[[假设检验概述|假设检验]]方法的适用条件、主要任务与公式对照表。

| 方法 | 使用前提与目标 | 统计量或关系 |
| --- | --- | --- |
| [[z检验]] | 正态独立样本、已知总体标准差时，精确检验总体均值；其他情形另查渐近条件 | $Z=(\bar X-\mu_0)/(\sigma/\sqrt n)$ |
| [[t检验]] | 正态独立样本、方差未知，单样本均值检验为精确 t；配对检验对差值建模，Welch 为近似 | $T=(\bar X-\mu_0)/(S/\sqrt n)$，单样本自由度 $n-1$ |
| 分类频数卡方检验 | 独立观测的分类频数，检验拟合或独立性；期望频数与自由度须足以支持渐近近似 | $\chi^2=\sum_i(O_i-E_i)^2/E_i$，见[[分布拟合检验]] |
| [[F检验]] | 两组相互独立的正态样本，检验两总体方差之比 | $F=(S_1^2/S_2^2)/(\sigma_1^2/\sigma_2^2)_0$ |
| [[单因素试验的方差分析]]（ANOVA） | 独立正态同方差误差模型，检验多个总体均值相等 | $F=[SSA/(k-1)]/[SSE/(n-k)]$ |
| 正态性检验 | 如 Shapiro–Wilk，用数据检查偏离正态的证据；不拒绝不能证明正态 | 各方法有不同统计量，须结合样本量与 Q–Q 图解释 |
| [[秩和检验]]（非参数检验） | 仍需独立性、抽样结构等条件；秩和与配对符号秩检验的假设不同 | 无统一公式；不能概括为无需分布假设或一律检验中位数 |
| [[多元线性回归]]（回归推断） | 回归模型本身不是单个检验；精确系数 t/F 推断需相应误差模型及设计满秩 | $Y=X\beta+\varepsilon$，对指定系数或约束构造 t/F |
| 相关性检验 | 独立成对的二元正态样本、非退化且 $n>2$ 时检验总体相关系数为零 | $T=r\sqrt{(n-2)/(1-r^2)}\sim t(n-2)$；$r$ 本身是[[相关系数]]估计值 |
| 贝叶斯模型比较 | 指定模型、参数先验及模型先验，计算边缘似然；与 p 值检验不同 | 后验赔率 = 先验赔率 × Bayes 因子 |

贝叶斯参数更新与模型比较相关，但不是同一个任务。原先的更新公式为
$$p(\theta\mid X)=\frac{p(X\mid\theta)p(\theta)}{p(X)},$$
其中连续参数使用密度；见[[贝叶斯定理]]、[[后验概率]]与[[似然函数]]。选择检验首先看所问参数、数据生成方式和独立结构，再检查精确或近似分布的条件；样本量 30 不是 z/t 的通用分界。
