# 自动索引
```dataview
LIST
WHERE file.folder=this.file.folder
AND contains(dlink,link(this.file.name))
```
# 孤立笔记
```dataview
LIST
WHERE file.folder=this.file.folder
AND !contains(file.name,this.file.name)
AND !contains(dlink,link(this.file.name))
```
