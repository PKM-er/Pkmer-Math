# 自动索引

```base
filters:
  and:
    - file.folder == this.file.folder
    - file.name != this.file.name
views:
  - type: list
	name: 列表
```

# 孤立笔记

```base
filters:
  and:
    - file.folder == this.file.folder
    - file.name != this.file.name
    - or:
        - '!file.hasProperty("dlink")'
        - '!dlink.contains(this)'
views:
  - type: list
	name: 列表
```
