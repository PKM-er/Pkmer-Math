本仓库的使用分两种: 
## 作为本地Obsidian仓库打开

### 方式一（推荐）：下载 Release 源码包
1. 打开 Release 页面: https://github.com/PKM-er/Pkmer-Math/releases
2. 下载最新版本的 Source code 压缩包（zip 或 tar.gz）
3. 解压到本地任意目录
4. 使用 Obsidian 打开解压后的文件夹

> [!tip] 为什么优先推荐下载 Release
> - 无需安装 git、无需命令行，开箱即用
> - 源码包已瘦身（约 2 MB），排除了 `Other/pdf参考资料`、`Other/数学分类`、`.github` 等大文件与配置，轻量易用
> - 适合绝大多数学习者

### 方式二：Git Clone 完整仓库
若需要完整内容（含 PDF 参考资料）或想持续跟进更新，可克隆完整仓库:
1. 克隆此仓库到本地
	```shell
	git clone https://github.com/PKM-er/Pkmer-Math.git
	```
	若希望自定义本地仓库的名称(如想要文件夹名称为Math, 而不是PKM-Math): 
	```shell
	git clone https://github.com/PKM-er/Pkmer-Math.git Math
	```
	> 注意：完整克隆体积较大（PDF 占大头）。如果不需要 PDF，可按[[本地排除文件#排除已被 Git 跟踪的大目录|本地排除文件]]使用 partial clone + sparse-checkout，避免把“工作区不显示”和“首次不下载大文件”混为一谈。
2. 使用Obsidian打开下载的本地仓库文件夹

### 使用入口
根据个人习惯, 选择任意一个主页面板(MOC)使用: 
- [[-高等数学-]]: 仅学习高等数学, 不进行开发, 不系统学习进阶知识
- [[高等数学.base]]: 查看和管理所有文件及YAML元数据
- [[Home]]: 兼顾高等数学学习和轻度开发的Callouts面板
- [[-高等数学进阶-]]: 学习更深的理论知识, 仅作补充, 暂时不作为本库的主要内容
- 除此之外, 还可以使用和查看自定义 Base 查询
