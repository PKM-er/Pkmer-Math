# `.gitignore` 与本地忽略

仓库根目录的 `.gitignore` 是共享配置，当前不止一条规则；它同时约束开发工具、日志、个人 Obsidian 状态和内部维护目录。本文不再复制一份容易过期的“模板”，实际规则以仓库根目录 `.gitignore` 为准。

普通使用者和贡献者不要为了个人草稿修改共享 `.gitignore`。只在本机忽略未跟踪文件时，编辑 `.git/info/exclude`：

```gitignore
# 仅对当前 clone 生效，不会提交到仓库
我的草稿/
临时笔记.md
```

`.git/info/exclude` 不能隐藏已经被 Git 跟踪的文件；若要让大型已跟踪目录不出现在工作区，参见[[本地排除文件#排除已被 Git 跟踪的大目录|本地排除文件]]。

仓库当前没有 CODEOWNERS 强制审批规则，因此不能把“建议单独审查 `.gitignore`”表述成平台已经强制保护。
