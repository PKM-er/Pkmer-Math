复数的乘幂与开方在极坐标形式下最简洁。设 $z = r(\cos\theta + i\sin\theta) = re^{i\theta}$，$n$ 为正整数，则

$$z^n = r^n(\cos n\theta + i\sin n\theta) = r^n e^{in\theta}$$

## 棣莫弗公式
$(\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta$ 是 $r=1$ 时的特例。将其按二项式展开后对比实部与虚部，可得 $\cos n\theta$、$\sin n\theta$ 用 $\cos\theta$、$\sin\theta$ 的显式表达式。

## n 次方根
方程 $z^n = w$（$w\neq 0$）在复数域内恰有 $n$ 个不同的根。若 $w = \rho e^{i\varphi}$，则

$$z_k = \rho^{1/n} e^{i(\varphi + 2k\pi)/n}, \quad k = 0, 1, \dots, n-1$$

这些根均匀分布在以原点为圆心、$\rho^{1/n}$ 为半径的圆周上，相邻两根的辐角相差 $\dfrac{2\pi}{n}$。

## 示例
求 $z^4 + 1 = 0$ 的根。由 $z^4 = -1 = e^{i(\pi + 2k\pi)}$，得

$$z_k = e^{i(\pi+2k\pi)/4}, \quad k = 0, 1, 2, 3$$

即 $e^{i\pi/4}$、$e^{i3\pi/4}$、$e^{i5\pi/4}$、$e^{i7\pi/4}$，四个根在单位圆上等距分布（见[[极点的计算方法]]）。
